# 🛸 《深空當舖》系統擴充：動態市場與圖鑑系統需求

我們需要讓遊戲具備長線可玩性與靈活更新能力，請幫我們產出以下兩個模組的 Luau 程式碼：

### 1. `CodexSystem.luau` (圖鑑與成就加成系統)
- 記錄玩家已鑑定的物品圖鑑解鎖狀態。
- 提供 `CheckSetBonus(playerData)` 函式：當玩家集齊特定套裝（例如 ["Item_001", "Item_002", "Item_003"]）時，回傳對應的永久店鋪 Buff（如金幣加成倍率、客人耐心值加成）。

### 2. `GalacticNewsSystem.luau` (銀河動態新聞與市場波動模組)
- 設計一個動態事件觸發器，包含至少 3 種銀河新聞（如：星際戰爭、帝國禁令、淘金熱）。
- 每個新聞事件會附帶影響因子（`PriceModifier` 價格倍率、`FakeChanceModifier` 假貨機率加成）。
- 提供 `GetMarketStatus()` 供伺服器端計算每日物品的最終交易價格。

請確保程式碼乾淨且易於未來新增更多新聞與圖鑑套裝！
